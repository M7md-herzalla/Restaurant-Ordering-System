# MOJ 🍔

A restaurant website built with HTML, CSS, vanilla JavaScript, and Firebase — a learning project that keeps growing, one feature at a time.

### Features

- Email and Google sign-in
- User profiles
- Menu powered by Firestore
- Personal cart saved for each account
- Responsive design for mobile and desktop

[Check it out here](https://moj-resturant.netlify.app)
